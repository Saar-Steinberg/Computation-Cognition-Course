## Running notebooks

Extract each submission ZIP into its own folder. Open the R Markdown notebook in RStudio and use its folder as the working directory so relative dataset paths resolve. Install the required packages, including `rmarkdown`, `knitr`, `ggplot2`, `dplyr`, and `tidyr`. HTML rendering requires Pandoc, which is bundled with RStudio. Download HTML reports to view them in a browser.

The notebooks have not been rerun for this upload. Random simulations may produce different outputs.
