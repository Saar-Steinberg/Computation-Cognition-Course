# Computation & Cognition

R Markdown coursework exploring exploratory data analysis, stochastic simulation, decision-making, and reinforcement learning. Each assignment combines executable R code with the original task context.

| Notebook | What to inspect | Data |
| --- | --- | --- |

## Run locally

1. Clone or download this repository and open it in RStudio.
2. Install the notebook dependencies once:

```r
install.packages(c("rmarkdown", "knitr", "ggplot2", "dplyr", "tidyr", "gridExtra"))
```

3. Open a notebook from the table and select **Knit**. RStudio provides Pandoc for HTML rendering. For PDF output, install a LaTeX distribution separately.

To render the reinforcement-learning notebook from the repository root:

```r
rmarkdown::render("assignments/HW2/HW2.Rmd", output_format = "html_document")
```

When running chunks manually, set the working directory to the notebook's folder. The CSV files are placed alongside the notebooks so their existing relative paths work. Exercise 3's alternate versions have a second, identical copy of the episode dataset in their shared directory.

## Data and file guide

- `assignments/HW2/LearningData.csv`: original course learning data, with choices, rewards, Q values, prediction errors, agent type, player label, and trial number. Player labels follow the `Conservative_1` / `Reactive_1` pattern.
- `assignments/EX3/EX3/BreakingBadData.csv`: original episode data with season, title, air date, rating, vote count, and description. Values are preserved as supplied.
- `assignments/EX3/assignment.Rmd` and `assignments/EX3/Tirgul 3 - classwork BreakingBad.Rmd`: alternate Exercise 3 versions retained from the original coursework. Start with the submission notebook linked above.
- `assignments/HW1/HW1.Rmd`: the supplied filename is retained; its internal assignment title says “Homework 4.”

Only datasets used by these assignments are included. Unrelated experimental datasets and instructor tutorial materials are outside this repository's scope.
